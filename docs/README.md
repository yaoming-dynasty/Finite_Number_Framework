# Documentation Index

This directory contains the formal, mathematical, and verification materials for the Finite Number Framework.

## Core documents

- [manuscript.md](./manuscript.md)  
  The main journal-style manuscript presenting the framework, definitions, and formal discussion.

- [decomposition_bridge.md](./decomposition_bridge.md)  
  The decomposition-bridge document connecting magnitude space, logarithmic coordinates, the C(S) classification, inversion symmetry, and balance criteria.

- [composition_bridge.md](./composition_bridge.md)  
  The composition-bridge document describing how positive magnitudes and their logarithmic relations combine into larger structures.

- [transformation_bridge.md](./transformation_bridge.md)  
  The transformation-bridge document describing how magnitude transformations, coordinate changes, and boundary shifts affect the system.

- [verification.md](./verification.md)  
  A practical verification procedure for checking the framework on finite sets and boundaries.

- [proof_appendix.md](./proof_appendix.md)  
  A formal appendix containing lemmas, propositions, and proofs supporting the main theory.

- [theorem_index.md](./theorem_index.md)  
  A theorem numbering and cross-reference index for the framework.

## Relationship between the documents

- The [manuscript.md](./manuscript.md) provides the main exposition.
- The [decomposition_bridge.md](./decomposition_bridge.md) explains how the framework links magnitude space, logarithmic coordinates, and classification.
- The [composition_bridge.md](./composition_bridge.md) explains how local magnitude relations combine into larger structures.
- The [transformation_bridge.md](./transformation_bridge.md) explains how transformations and frame changes affect the same underlying structure.
- The [verification.md](./verification.md) operationalizes the mathematical rules into a concrete checking procedure.
- The [proof_appendix.md](./proof_appendix.md) gives the underlying formal proof structure.
- The [theorem_index.md](./theorem_index.md) offers stable references for the major results and definitions.

1. [manuscript.md](./manuscript.md)
