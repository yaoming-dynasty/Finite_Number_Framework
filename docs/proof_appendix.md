# Formal Proof Appendix

## Introduction

This appendix gives a compact but fully formal set of lemmas, propositions, and proofs for the Finite Number Framework. The intent is to make the framework auditable as a mathematical structure rather than merely interpretive.

Throughout, let Ω = ℝ_{>0}. We write

q(x) := ln(x)

for the canonical logarithmic coordinate, and for any boundary B > 0,

P_B(x) := ln(x / B).

The basic assumptions are:

- all magnitudes are positive;
- multiplication on Ω becomes addition under q;
- inversion becomes negation under q;
- boundary changes correspond to translations of positions;
- relative positions are invariant under changes of boundary.

---

## Lemma 1. Logarithm converts multiplication to addition.

For all x, y ∈ Ω,

q(xy) = q(x) + q(y).

Proof.
By the definition of q,

q(xy) = ln(xy) = ln(x) + ln(y) = q(x) + q(y).
QED.

---

## Lemma 2. Logarithm converts division to subtraction.

For all x, y ∈ Ω,

q(x/y) = q(x) - q(y).

Proof.
By the definition of q,

q(x/y) = ln(x/y) = ln(x) - ln(y) = q(x) - q(y).
QED.

---

## Lemma 3. Inversion negates the logarithmic coordinate.

For all x ∈ Ω,

q(1/x) = -q(x).

Proof.
By the definition of q,

q(1/x) = ln(1/x) = -ln(x) = -q(x).
QED.

---

## Proposition 4. Boundary changes act by translation.

For all x, B, B' ∈ Ω,

P_{B'}(x) = P_B(x) + ln(B / B').

Proof.
Using the definition of P_B,

P_{B'}(x) = ln(x / B')
= ln(x / B) + ln(B / B')
= P_B(x) + ln(B / B').
QED.

---

## Proposition 5. Relative positions are boundary-invariant.

For all x, y, B ∈ Ω,

P_B(x) - P_B(y) = ln(x / y).

Proof.
Compute:

P_B(x) - P_B(y)
= ln(x / B) - ln(y / B)
= ln((x/B) / (y/B))
= ln(x / y).
QED.

---

## Corollary 6. Relative relation is frame-independent.

For all x, y ∈ Ω and all boundaries B, B' > 0,

P_B(x) - P_B(y) = P_{B'}(x) - P_{B'}(y).

Proof.
By Proposition 5,

P_B(x) - P_B(y) = ln(x / y)

and similarly,

P_{B'}(x) - P_{B'}(y) = ln(x / y).

Therefore both sides are equal.
QED.

---

## Proposition 7. Inversion under a normalized boundary.

If B = 1, then for all x ∈ Ω,

P_1(1/x) = -P_1(x).

Proof.
By definition,

P_1(x) = ln(x / 1) = ln(x).

Hence,

P_1(1/x) = ln(1/x) = -ln(x) = -P_1(x).
QED.

---

## Proposition 8. Inversion swaps inside and outside relative to a normalized boundary.

For all x ∈ Ω, if B = 1, then

P_1(x) < 0  iff  P_1(1/x) > 0.

Proof.
By Proposition 7,

P_1(1/x) = -P_1(x).

Therefore the sign of P_1(1/x) is the opposite of the sign of P_1(x). In particular, if P_1(x) < 0, then P_1(1/x) > 0, and vice versa.
QED.

---

## Definition 9. Inversion-closed set.

A set S ⊆ Ω is inversion-closed if

x ∈ S  implies  1/x ∈ S.

---

## Proposition 10. Pairwise cancellation in inversion-closed sets.

Let S be inversion-closed and finite. Then for every pair x, 1/x ∈ S,

q(x) + q(1/x) = 0.

Proof.
By Lemma 3,

q(1/x) = -q(x).
Therefore,

q(x) + q(1/x) = q(x) - q(x) = 0.
QED.

---

## Corollary 11. Total cancellation over a finite inversion-closed set.

If S is inversion-closed and finite, then

Σ_{x∈S} q(x) = 0

when all terms are grouped in paired form (x, 1/x).

Proof.
Partition S into inverse pairs {x, 1/x}. By Proposition 10, each pair sums to zero. Summing over all disjoint pairs gives zero.
QED.

---

## Definition 12. Two-boundary classification.

Let 0 < B1 < B2 and let S ⊆ Ω. For each x ∈ S, define

A(x) := P_{B1}(x),
B(x) := P_{B2}(x).

Then x belongs to:

- the inside of B1 if A(x) < 0;
- the interval between B1 and B2 if A(x) ≥ 0 and B(x) ≤ 0;
- the outside of B2 if B(x) > 0.

The induced classification is denoted C_{B1,B2}(S).

---

## Proposition 13. The two-boundary classification is a partition.

For every S ⊆ Ω and every pair of boundaries 0 < B1 < B2, the set S is partitioned by C_{B1,B2}(S) into exactly three mutually exclusive classes.

Proof.
Fix x ∈ S. Then exactly one of the following is true:

1. P_{B1}(x) < 0;
2. P_{B1}(x) ≥ 0 and P_{B2}(x) ≤ 0;
3. P_{B2}(x) > 0.

These conditions are mutually exclusive because they correspond to disjoint sign conditions on the two positions. They are exhaustive because every real number falls into one of the three cases above.
QED.

---

## Definition 14. Many & Few.

Let S ⊆ Ω and 0 < B1 < B2. Define

Many&Few(S; B1, B2) := (S, C_{B1,B2}(S)).

---

## Proposition 15. Many & Few is boundary-sensitive but invariant under boundary shifts.

Let B1, B2 and B1', B2' be two pairs of boundaries. Then the classification generated by the first pair and the classification generated by the second pair differ only by translation of the coordinate system, not by the underlying relational structure.

Proof.
By Proposition 4, changing a boundary from B to B' adds the constant ln(B / B'). Thus every position shifts by the same amount. The relative order of points is preserved under translation, so the classification changes only by the induced origin shift, not by an alteration of the relational structure itself.
QED.

---

## Proposition 16. The framework is algebraically isomorphic to the additive real line.

The map q : Ω → ℝ defined by q(x) = ln(x) is a group isomorphism from (Ω, ×) onto (ℝ, +).

Proof.
By Lemma 1, q(xy) = q(x) + q(y). So q preserves multiplication as addition. By Lemma 3, q(1/x) = -q(x), so inversion corresponds to negation. The map is bijective because ln : ℝ_{>0} → ℝ is a bijection. Therefore q is a group isomorphism.
QED.

---

## Proposition 17. Relative comparison is invariant under boundary change.

For all x, y, z ∈ Ω and all boundaries B, B' > 0,

(P_B(x) - P_B(y)) = (P_{B'}(x) - P_{B'}(y)).

Proof.
By Proposition 5,

P_B(x) - P_B(y) = ln(x / y)

and

P_{B'}(x) - P_{B'}(y) = ln(x / y).

Hence they are equal.
QED.

---

## Summary of Formal Structure

The core of the framework is therefore captured by the following finite set of identities:

1. q(xy) = q(x) + q(y)
2. q(x/y) = q(x) - q(y)
3. q(1/x) = -q(x)
4. P_{B'}(x) = P_B(x) + ln(B / B')
5. P_B(x) - P_B(y) = ln(x / y)
6. q(x) + q(1/x) = 0 for inverse pairs
7. Many&Few(S; B1, B2) is a partition induced by two boundaries

These make the framework testable as a formal mathematical structure.
